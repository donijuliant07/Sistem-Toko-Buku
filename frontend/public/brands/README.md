# Logo marketplace

Dipakai `frontend/components/books/marketplace-sources.tsx` (`<MarketplaceLogo>`) untuk menandai sumber harga di
perbandingan harga buku. Semua logo milik pemilik merek masing-masing dan hanya
dipakai untuk memberi tahu pengguna penawaran itu datang dari mana.

| Berkas | Sumber | Keterangan |
|---|---|---|
| `tokopedia.svg` | [Wikimedia Commons — File:Tokopedia.svg](https://commons.wikimedia.org/wiki/File:Tokopedia.svg) | logotype resmi, hijau `#42b549` |
| `blibli.svg` | [simple-icons 16.36.0](https://unpkg.com/simple-icons@16.36.0/icons/blibli.svg) | ikon, biru `#0072FF` |
| `lazada.svg` | [Wikimedia Commons — File:Lazada (2019).svg](https://commons.wikimedia.org/wiki/File:Lazada_(2019).svg) | logotype, biru `#000083` |
| `gramedia.svg` | [Wikimedia Commons — File:Toko Buku Gramedia.svg](https://commons.wikimedia.org/wiki/File:Toko_Buku_Gramedia.svg) | logotype, biru `#2056ae` + merah `#ed1c24` |
| `open-library.svg` | [Wikimedia Commons — File:Open Library logo.svg](https://commons.wikimedia.org/wiki/File:Open_Library_logo.svg) | logotype, biru `#518abe` |

Marketplace tanpa berkas logo di sini (Shopee, Periplus, Google Books) tampil sebagai
chip huruf netral — sama seperti slug demo.
